# Momenta brand fonts (not committed)

Gilroy and FT Calhern are licensed fonts and this repository is public, so the
font files are git-ignored. To get the full Momenta typography, copy these
files from the Momenta design system into this folder on the machine (or Repl)
that serves the app:

- `Gilroy-ExtraBold.otf`
- `Gilroy-Light.otf`
- `FTCalhern-CondensedRegular.ttf`

Without them, `src/ui/styles/theme-momenta.css` falls back to Inter.
